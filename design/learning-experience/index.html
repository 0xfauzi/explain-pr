Design · 7 Nov 2026

You build in chat. You learn in the Room. One card moves between them.

The agent does the work. At two moments in a task, it stops and asks you one question: before it builds, and after it works. You answer where you are: in chat on the laptop, or in the Room on your phone.

The answer comes home with nothing copied. The agent grades it against an answer it fixed before it asked. One line puts you back in the build. Days later the idea comes back as a new question, and your record shows what you can do without the agent.

What seamless means

Not learning all the time. Four things you can test.

Interruption research says a question at the wrong moment costs more than it teaches. So the agent asks only at breaks the work already has, and every detour ends with the way back.

01

No copying

You never copy a question, an id, a link or an answer from one place to another.

Test: 0 copy and paste actions in a recorded session.
02

No re-explaining

Chat, the Room on the desktop and the Room on the phone show the same card in the same state.

Test: open one card at three doors; same prompt, same state.
03

No stall

The build waits only for a prediction you chose to answer. "Not now" is two words or one tap.

Test: "Not now" to the next tool call in under 5 s.
04

Resume in one line

Every learning exchange ends with the same cue: Back to: <task>. Next: <step>.

Test: every graded reply ends with that line.

How it ships

Phase 1 uses only what we tested. Each upgrade has a fallback that already works.

One card, one store, many doors. A small lwb MCP server owns each card. The Room is a private claude.ai page that opens beside the session and in the Claude app on the phone.

Phase 1tested

Pull on the next message

  • The skill tells the agent when to ask. It calls lwb_seal, lwb_post, lwb_lock.
  • A Room answer is locked in the page's database and graded on the page.
  • Your next message pulls it into the record. One extra turn at most.
Phase 2after named tests

The tap rings the session

  • Hooks make the moments automatic: session start, a failing test, tests passing.
  • Lock my answer on the phone also wakes the session. The grade is in chat with no extra turn.
  • One push a day at most, and never while you are at the machine.
Phase 3end state

Every harness, every door

  • A pane beside the chat on the local desktop app while the agent keeps building.
  • Codex and other agents through MCP forms and an inbox of sealed answers.
  • The same card, the same lock, the same record in each.
