The one sheet that asks. It is the only bordered surface in the product, and the only place the highlighter is used.

- The bar names the moment and the entry number. The order below it is fixed: where this is, what happened, the evidence, the question, the cells, Lock.
- The evidence comes before the question so the person reads it first. Each evidence row is numbered in a ruled gutter and joins the test name to its path with a leader.
- Wrap the question's words in `<mark>`. One question per sheet.
- Show the keys under the cells in `fh-keys`.
- The footer says how it is checked, in `fact`.
- Never show a result on a sheet. A result is a Spread on its own page.
