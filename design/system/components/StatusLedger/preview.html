In Claude Code, on Python projects that use pytest.

  • Revert testworks

    When the agent finishes a change with tests, you pick the new test that would still pass with the change undone. Checked by undoing the change and running the tests.

  • Call itworks

    When a test is failing, you pick where the cause is, before a fix exists. Checked by where the fix landed, and by undoing the fix and running the test again.

  • Briefworks

    At the start of a larger task, you name one check that fails now and will pass when the task is done. Checked by running it with the change and with the change undone.

  • The Roomworks

    A page served at 127.0.0.1 with the open question, results, a journal of every call, and settings.

  • The recordworks

    A git repo at ~/.firsthand/record: on your machine, outside your projects, with no remote.
