What runs today beside what is only designed, as two ledgers. Site only.

- Two columns in `fh-twocol`. The left, `fh-state`, opens with a solid 2px `ink` rule: it runs. The right, `fh-state--designed`, opens with a dashed `rule-strong` rule, the same dash as the Not scored mark: it does not run yet.
- Each column head is a `label` with what the column is on the left and its state on the right, then one line of `ui-sm` that says where it applies.
- Each item is a row: its name in `voice-md`, a leader, and its state in `fact` ("works", "not built"), then one or two sentences in `ui-md`. Names in the designed column are weight 400 and `ink-2`.
- The state is always written in words. Never use a tick, a cross, a color or a progress bar, and never count the items.
- Do not move an item to the left column until it has been seen to work.
- Below 760px the columns stack, "Works today" first.
