The Journal: every call and every note, newest first, as one ledger.

- A call is an entry row: number and time in the margin, the moment, the task as a link, the verdict at the right, then YOU and RUN.
- A note is a note row in the same ledger, in time order.
- An entry with no run to show keeps the RUN tag, and its sentence is set in `ui` (`say`), because the engine is speaking, not a run.
- Empty, the Journal is one `fh-row--blank`: "No answers or notes yet."
