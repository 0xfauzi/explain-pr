06Version 0.6.0

The earlier skill is still available

This repository also contains learning-while-building, version 0.6.0. It is an Agent Skill for Claude Code and for other agents that read Agent Skills. You choose the tasks. On those tasks, it asks you a question before the agent builds. After the build, it asks you to explain the code. It asks again after some days.

It installs separately and does not need Firsthand. From version 0.6.0, it keeps its record in ~/.learning-while-building, outside your project. If an older version left a .learning folder in your repository, the README tells you how to move it.

In Claude Codeneeds Python 3.10 or later and git
