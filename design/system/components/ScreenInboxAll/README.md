The Inbox with everything it can hold at once: one open question, an answer waiting for its run, notes, and results not opened yet.

- The open question is a sheet stub: the bar, where it is, the task in `voice`, and one button, Open. It does not show the evidence or the question, and it has no highlighter. Opening the sheet is what marks a question as seen.
- Each section opens with a `fh-sec` label line and a ledger with the double rule. A section with nothing in it is not drawn.
- Order is fixed: Now, Waiting, Notes, Results.
- The count on the Inbox tab is the number of open questions, on `mark-bright`.
