A thing that opens in place. There are two: More on a result, and Full test inside an evidence row.

- `fh-more` is a native `details`. Its summary is a ruled line: the word in a `label`, a leader, then "show" or "hide" in `fact`. No chevron, no icon.
- Inside, each kind of detail is a margin row (`fh-finding fh-finding--text`): the label in the margin column, the content beside it. Lists of facts use `fh-facts` with leaders. Commands are `fh-cmds`: `paper-sunk`, one command per line behind a `$`.
- `fh-more--in` is the small form inside an evidence row: the words "Full test", underlined. It opens a `fh-code` listing.
- `fh-code` is a listing with real line numbers in a gutter. Mark each assertion line `is-key`. Lines wrap; the listing never scrolls sideways.
- Opening and closing is instant. Do not animate height.
