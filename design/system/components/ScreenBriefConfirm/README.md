The Brief's confirm: the person's line, the test the agent wrote for it, and one question.

- The person's line comes first, as written, in blue italic with the time it was locked.
- Then the test as evidence, with Full test.
- The question is in `voice` with the highlighter. The test's name is not part of the sentence on screen: it sits under it in `fact` (`fh-q__name`), because a test name is never set in `voice`.
- Yes and No are word cells. A tap locks.
