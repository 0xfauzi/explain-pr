Three weights of action. One primary button per screen.

- Primary (`fh-btn`): the next step. Ink fill, `ink-2` on hover. It never turns `call`: blue is the person's answer.
- Second (`fh-btn--second`): a way out that changes nothing.
- Quiet (`fh-btn--quiet`): Skip, Undo, Wrong start. Underlined text, still 48px tall.
- If a key does the same thing, show it as a `fh-kbd` keycap inside the button.
- The label says what happens. Never "OK".
