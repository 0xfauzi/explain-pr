The Room, inbox in the plain case: one open question and the Today list. An example screen, copied from the Room's markup.

- The open question is a sheet stub under Now: the bar, where it is, the task, and one button, Open. The stub does not show the evidence or the question.
- Today lists the questions asked today, the dial and Quiet.
- ScreenInboxAll shows the inbox with every section it can hold. ScreenInboxEmpty shows it with no open question.
