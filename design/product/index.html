Firsthand Product summary. Nothing built yet. 7 Nov 2026.

Working name, not yet cleared [unverified: trademark, registries]

Know what you can still do without your agent. Get better at it while you build.

Firsthand installs into the coding agent you already use. At a few breaks in the build, it asks you to think first. Days later it asks again, in a new form. A private record on your machine shows what you have shown without the agent, how it was graded, and how long ago.

Why: in a study of people learning a new library, those who let AI write the code learned less. Those who asked conceptual questions kept their learning (Shen and Tamkin 2026, arxiv.org/html/2601.20245v2).

The promise you can check in five minutes: install it, answer three questions written by people, in a prompt your agent cannot read. It tells you how you did without your agent, and how it graded you.

The launch claim is about honesty, not results: "It tells you when you got worse." No claim that it makes anyone better until a study shows it.

The product

Three parts

1

The Checkup

Once a month, only if you start it. A short task in a real repo you have never opened, agent off, in a sealed container. Tests written by people, run on a server. Over several Checkups it tells you if you got better or worse.

2

The loop

Free and open source. Lives inside your agent. Asks you to predict, name a cause, write one line, or review a pull request first. Brings ideas back days later, at most 3 a day.

3

The record

A private map in a git repo on your machine. No remote unless you add one. A level goes down when you forget, and shows how long since it was checked.

The loop is easy to copy. The scarce parts are the human-written question bank and the Checkup task set. No public launch until both are live.

Five moves, at natural breaks

The build always wins. No move blocks the agent. Every move has a one-word skip, and "just tell me" always works.

What a level means

Only delayed answers, without help, on new questions, count. Right answers in the moment show what you can do now, not what you learned (Soderstrom and Bjork 2015, pubmed).

Not yet
The start, or one step down after a delayed miss or "don't know".
Recalled
Two right delayed answers, on two items, on different days.
Applied
Two right on new instances: another file or project, topic name hidden.
Held
Right at a longer gap on an unseen question, plus one other source.
Met is a separate list, not a level: ideas you explained, wrote a line for, or answered with help or in the moment.

Architecture

One engine on your computer. Many ways in.

  • Tiers stack. Every surface has T0. Each tier above it adds something. The engine detects what is there and always returns complete text.
  • The pad is how answers count. A chat answer passes through the agent, so it is recorded as relayed and counts as Met. An answer typed in the pad never reaches the agent or its logs.
  • Hooks never approve anything. They call a pinned absolute path, and never return allow or deny. Claude Code hooks can return allow [verified: code.claude.com/docs/en/hooks].
  • Grading by running code first. In v1 only tests and people move a level. A model grader can move one only after its version passes a gate against human grades.
  • Untrusted code runs in a container with no network, or not at all. Checkup tasks and Replay drills need one.
  • Nothing is sent by default. Answers typed in the agent's chat are part of that chat, and the agent's company sees them. The install says so.

Risks

The three that could end it

efficacy

It does not make people better weeks later

The founding study measured right away, with 52 people (arxiv). A lab check of the current skill comes before the engine.

retention

Nobody comes back

The value is long term and the cost is now (Lehmann 2025, arxiv). 30-day return of cold users gates the build.

funding

No one funds it

A large build with no revenue before courses or teams, and a vendor can copy the loop. Lead with the scarce parts; test buyers in v0.
