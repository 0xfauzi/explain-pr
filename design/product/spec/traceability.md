## Conflicts between judges, and how they were resolved

| Conflict | Resolution |
| :- | :- |
| Strategist: replay drills are the v1 wedge. Staff engineer: the miner makes v1 unbuildable | Trace and Check, which need only read-only history and a scratch run of one function, carry the v1 wedge. Replay ships in v1 only for languages that pass E2 |
| Learning scientist: G4 practice needs a v1 path. Target users: Spot out of v1 | Check drills on real past agent diffs give G4 practice with nothing seeded |
| Designer: fade the header. Target users: why-now and skip on every question | Both kept, in one short clause after three exchanges |
| Target users: Light in week one. Founder decision 2: your line on | Standard with a low cap and your line only on confirmed-new ideas |
| Designer: no silent loss in cloud. Platform research: never write a branch | Encrypted side branch only with one yes, not in public repos, merge-blocked; founder decides |
| Staff engineer: no local page in v1. Designer: at most one local page | None in v1; the Room returns in v2 only if the text map proves insufficient |
